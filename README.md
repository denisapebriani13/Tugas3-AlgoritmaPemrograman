# Tugas 3 - Algoritma dan Pemrograman

Program Perhitungan Gaji Karyawan

## 📋 Deskripsi Tugas
Program ini dibuat untuk menghitung **total gaji karyawan** berdasarkan golongan dan jumlah jam lembur sesuai dengan ketentuan yang diberikan.

## ✨ Fitur Program

- Menggunakan **Array** untuk menyimpan data gaji pokok dan persentase lembur
- Menggunakan **IF Statement** untuk pengecekan golongan dan jam lembur
- Input golongan karyawan (A, B, C)
- Input jumlah jam lembur
- Perhitungan gaji lembur dengan persentase bertingkat
- Tampilan output yang rapi dengan format Rupiah

## 🛠️ Spesifikasi Teknis

- **Bahasa Pemrograman**: Java
- **IDE**: Apache NetBeans (Java with Ant)
- **Konsep yang digunakan**: Array, IF-Else, Operator Aritmatika, Scanner

## 📊 Data Sesuai Soal

### Golongan Karyawan:
| Golongan | Gaji Pokok     |
|----------|----------------|
| A        | Rp 5.000.000   |
| B        | Rp 6.500.000   |
| C        | Rp 9.500.000   |

### Persentase Lembur:
| Jam Lembur     | Persentase |
|----------------|------------|
| 1 Jam          | 30%        |
| 2 Jam          | 32%        |
| 3 Jam          | 34%        |
| 4 Jam          | 36%        |
| ≥ 5 Jam        | 38%        |

## 🚀 Cara Menjalankan

1. Buka project di Apache NetBeans
2. Jalankan file `Tugas3AlgoritmaPemrograman.java`
3. Masukkan golongan (A/B/C)
4. Masukkan jumlah jam lembur
5. Program akan menampilkan total gaji
